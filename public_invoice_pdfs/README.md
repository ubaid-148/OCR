# Public invoice samples

This directory contains 111 invoice PDFs explicitly authorized by the repository owner for public distribution and Colab OCR diagnostics.

These documents contain real-world Arabic/English layouts and may include visible business/customer identifiers. They are source documents only, not verified JSON ground truth. Do not treat an OCR or vision response as a verified transcription without checking the corresponding PDF.

Rendered page images and temporary predictions should remain outside Git history unless intentionally reviewed for publication.
