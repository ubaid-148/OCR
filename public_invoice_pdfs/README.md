# Public invoice samples

This directory contains 111 invoice PDFs explicitly authorized by the repository owner for public distribution and Colab model preparation.

These documents contain real-world Arabic/English layouts and may include visible business/customer identifiers. They are source documents only, not verified JSON ground truth. Do not treat an OCR or cloud-model response as a training label until every field and item row has been checked against the corresponding PDF.

Corrected annotations, rendered page images, predictions, checkpoints, and model weights must remain outside the Git worktree.
